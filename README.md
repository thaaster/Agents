# Custom AI Agents

A collection of custom AI agents for use with GitHub Copilot and other AI-powered tooling.

## Overview

This repository contains custom agent definitions that extend AI assistant capabilities with domain-specific knowledge and behavior.

## Structure

Each agent is defined in its own directory and includes:

- `agent.json` — Agent metadata and configuration
- `SKILL.md` — Instructions and domain knowledge for the agent

## Usage

Agents in this repository are picked up automatically by supported AI tooling when configured in your editor or environment.

## Contributing

1. Create a new directory for your agent.
2. Add an `agent.json` with the agent's name, description, and settings.
3. Add a `SKILL.md` with the agent's instructions and domain knowledge.
